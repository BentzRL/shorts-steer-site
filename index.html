Shorts Steer

Shorts Steer is a private analytics tool run by one operator for YouTube channels that have given it permission. It reads a channel's Shorts statistics and audience retention through the official YouTube Data API and YouTube Analytics API, and, when asked by the channel owner, uploads finished Shorts to that channel.

It is not a public service. Access is granted by a channel owner signing in with Google once and can be removed at any time from Google account permissions.
