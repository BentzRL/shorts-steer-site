Shorts Steer privacy policy

Last updated 1 November 2026.

What Shorts Steer is

Shorts Steer is a private tool operated by a single person (the operator) to analyse YouTube Shorts performance for the operator's own channel and for channels whose owners have asked the operator to help manage them. It runs on the operator's own computer. It is not offered to the public.

What data it accesses

When a channel owner signs in with Google and grants access, Shorts Steer uses the YouTube Data API and YouTube Analytics API to read:

  • the channel's identity (channel ID and title) and its list of uploaded videos with titles, descriptions, durations and publish dates;
  • per-video statistics such as views, likes, comments, shares, average view duration and audience retention curves.

With the YouTube upload permission, Shorts Steer can publish videos to a connected channel. It only does so when the operator explicitly starts an upload for that channel.

Shorts Steer does not access the Google account's email, contacts, other Google services, or any data outside the connected YouTube channel.

How data is stored

All data is stored in a local database on the operator's computer. Sign-in tokens are stored locally on the same computer and are used only to call the YouTube APIs on the channel's behalf. No data is sent to any third party, sold, or used for advertising.

How data is used

The data is used only to produce performance analysis and recommendations for the connected channel, which are shared with that channel's owner.

Google API Services User Data Policy

Shorts Steer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

A channel owner can revoke access at any time at myaccount.google.com/permissions. On request, the operator will delete all stored data for a channel.

Contact

Questions about this policy can be sent to the operator at the support email shown on the Google sign-in consent screen.
